# Inventory Management — Backend

NestJS + Prisma (PostgreSQL) + Zod.

## Cài đặt

```bash
npm install
```

## Run tests

```bash
# unit tests
$ npm run test

# unit tests, xem coverage (báo cáo HTML tại coverage/lcov-report/index.html)
$ npm run test:cov

# e2e tests (chưa viết — cần DB Postgres thật, xem test/jest-e2e.json)
$ npm run test:e2e
```
